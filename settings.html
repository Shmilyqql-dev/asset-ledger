数据存放位置

关于你的数据在哪里、安不安全
你的资产数据只保存在这台设备的浏览器里，不会上传到任何服务器。别人就算拿到同一个网址，打开的也是他自己的空白账本，看不到你的一个数字。
注意：清理浏览器数据 / 换设备 / 无痕模式关闭后会丢失，请养成每月导出一次 JSON 备份的习惯。

备份与恢复

换设备、多设备数据合并都靠这里
导出 JSON 是完整备份（资产 + 投资 + 渠道设置）。导入时可选「合并」或「覆盖」：合并只补缺失记录，适合电脑手机两边合并；覆盖会完全替换当前数据。

危险操作

清空后不可恢复，务必先备份
